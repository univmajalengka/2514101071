# Pertemuan 06-08 — Tugas Diskon

Program sederhana menggunakan fungsi/prosedur untuk menghitung diskon berdasarkan total belanja.

## Aturan Diskon

| Total Belanja | Diskon |
|---------------|--------|
| >= Rp 100.000 | 10% |
| >= Rp 50.000 dan < Rp 100.000 | 5% |
| < Rp 50.000 | 0% (tanpa diskon) |

## File

- `hitung-diskon.php` — implementasi dalam PHP
- `hitung-diskon.py` — implementasi dalam Python

## Contoh Output (total belanja Rp 120.000)

```
Total belanja: Rp. 120000
Diskon: Rp. 12000
Total yang harus dibayar: Rp. 108000
```

## Cara Menjalankan

PHP:
```bash
php hitung-diskon.php
```

Python:
```bash
python hitung-diskon.py
```
